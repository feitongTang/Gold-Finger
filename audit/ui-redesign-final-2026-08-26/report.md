## 交互验证

- 月份切换：在 2026-07、2026-08、2026-09 间切换，URL 与保存/空状态一致。
- 新建与更新：空月份“新建数据”和保存月“更新数据”均可展开表单；“收起记录”可关闭表单。
- 表单：保存月收入字段回填为 `31800`；空月份字段可聚焦。基金行可新增后移除，数量从 5→6→5，未保存测试改动。
- 校验错误：收入填写无效金额后，错误摘要可见，收入字段获得 `aria-invalid=true`、错误边框并重新获得焦点；输入内容仍保留。
- 保存成功：使用原值更新 2026-08 后，表单收起，状态显示“2026-08 已保存”，焦点回到 `H1 月度复盘`，净资产仍为 `¥373,600.00`。
- 趋势：资产/负债、收入/支出切换状态和图表可访问名称同步变化；24 个可聚焦数据点的透明命中区与 4px 可见圆点分离，hover/focus tooltip 保持正确坐标。
- 投资分配：可从“全部投资”进入“权益类”下一级，并通过“返回上一级”回到根层级。
- 历史披露：“查看趋势数据”可展开，表格包含净资产与投资资产等完整字段。
- 删除确认：永久删除警告、取消与确认操作均出现；仅执行取消，记录保持不变。
- 导出：操作后页面显示“备份已导出”及最近成功导出时间。内置浏览器未暴露下载事件，但应用的成功状态已更新。
- 恢复：文件选择器接受由本地 demo API 导出的有效 JSON；确认替换提示正确出现，随后取消，未执行破坏性恢复。

- Error：以无效 `DATABASE_FILE=/tmp` 冷启动后，实际浏览器显示共享 Header、640px 错误面板、“暂时无法读取财务记录”、数据不会自动删除的说明与重试按钮；随后恢复隔离 demo 服务。

## 键盘与可访问性风险

- 焦点：收入输入框获得焦点时显示 3px `rgba(152, 71, 59, 0.32)` 焦点环，边界未被视口或容器裁切；文件输入获得焦点后仍保留所选文件名。
- 点击目标：首次测量发现“删除本月”为 28px、趋势切换为 34.4px，根因是旧组件规则覆盖通用 40px 按钮高度；独立审查又发现 8×8px 的 SVG 数据点被 HTML-only 扫描漏掉。两项均已用测试驱动修复。修复后关闭状态 22 个 HTML 交互元素、展开表单 34 个 HTML 交互元素均不小于 40px，恢复确认按钮均为 40px；24 个 SVG 数据点在当前桌面缩放下的命中区最小为 62.3×62.3px。
- 状态信号：趋势切换使用 `aria-pressed` 与文字/背景共同表达选择状态；披露、确认与表单状态均不依赖 hover 才可辨认。
- 错误与危险状态：错误文本使用固定错误色与浅色背景；删除和恢复均提供明确的不可撤销说明及取消路径。
- 减少动态效果：独立审查发现全局 `transform:none` 会同时破坏金额单位垂直居中与 SVG tooltip 定位，现已改为只禁用 skeleton、按钮按压和趋势点缩放等非必要 transform。1440×900 无头 Chrome 使用 `--force-prefers-reduced-motion` 实测媒体查询为 `true`：金额单位仍保留 `matrix(1, 0, 0, 1, 0, -9.75)` 布局位移，趋势点非必要缩放为 `none`，tooltip 仍保留 `translate(146 87.927)` 并显示在非原点位置。
- 自动化限制：内置浏览器的 Tab/Shift+Tab 注入在链接、按钮、输入框和可滚动趋势表上均停留在原焦点；CUA、DOM CUA 与 locator press 均复现。因此无法把“完整顺序键盘巡检”标记为自动化通过。作为替代证据，本轮检查了实际焦点样式、焦点裁切、可访问名称、可逆交互及所有目标尺寸；仍建议在发布前用真实硬件键盘做一次人工 Tab 顺序复核。
