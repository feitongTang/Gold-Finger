# MVP Acceptance Record

验收日期：2026-08-20

## Environment

- 运行时：Node.js 24.15.0、Next.js 16.3.1 本地开发服务器
- 数据：独立临时 SQLite 数据库 `/tmp/gold-finger-task5.db`
- 桌面视口：1440 × 1000
- 手机视口：390 × 844
- 浏览器：Codex in-app browser

## Core flow

| 场景         | 操作与证据                                                                                          | 结果 |
| ------------ | --------------------------------------------------------------------------------------------------- | ---- |
| 空状态       | 打开全新数据库；复盘区提示先保存记录，历史区提示保存第一份记录，历史选择器禁用                      | Pass |
| 桌面闭环     | 1440 × 1000 下完成 2026-08 首次录入、同月更新、结果查看；新增 2026-09 后查看跨月变化并返回 2026-08  | Pass |
| 手机闭环     | 390 × 844 下完成 2026-10 首次录入、同月更新、结果查看及返回 2026-08 的历史导航                      | Pass |
| 结果查看     | 2026-08 显示资金分配、106,800 元净资产、资产结构及纳斯达克 100 分类汇总                             | Pass |
| 历史比较     | 2026-09/10 显示相对上次记录的变化；已有月份选择器可返回任意已保存月份                               | Pass |
| 桌面布局     | 1440 × 1000 下无页面级横向溢出，主操作与结果可见                                                    | Pass |
| 手机布局     | 390 × 844 下无页面级横向溢出或被裁切控件；趋势表只在有标签的区域内横向滚动                          | Pass |
| 加载状态     | 路由重载时显示结构化骨架，并提供“正在载入月度记录，请稍候”状态文本                                  | Pass |

| 键盘与无障碍 | 表单控件具有关联标签，错误/状态使用 live region，按钮与历史链接使用原生可聚焦元素，趋势滚动区可聚焦 | Pass |
