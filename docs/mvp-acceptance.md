## Task 8: 基金赎回与本月净投入

验收日期：2026-08-21

- 环境：Next.js 16.3.1 生产构建、本地临时 SQLite 数据库、Codex 应用内浏览器。
- 录入：新增基金后，本月净投入允许填写 `-10000`；当前市值等其他金额仍保留非负限制。
- 保存与回显：保存成功后重载页面，基金本月净投入仍显示 `-10000`。
- 复盘：收入 25,000 元、支出 8,000 元、赎回 10,000 元时，投资净投入显示 -10,000 元，月度结余显示 27,000 元。
- 运行状态：页面无框架错误覆盖层，浏览器控制台无警告或错误。

## Task 17: 月度记录生命周期与本地数据恢复

验收日期：2026-08-26

- 环境：Next.js 16.3.1 开发服务器、独立临时 SQLite 数据库、Codex 应用内浏览器。
- 全零记录：所有金额为 0 且没有基金时，首次提交只显示确认提示且不写库；明确选择“确认创建全零记录”后才保存。
- 单月删除：已有月份显示“删除本月”；展开后明确说明现金、基金与负债数据会永久删除且无法撤销；确认后仅目标月份消失。
- 导出状态：页面明确数据仅保存在本机；导出全部月份后显示成功反馈，并在当前浏览器中记录最近成功导出时间。
- 恢复：从导出的版本化 JSON 恢复前提示会永久替换全部当前记录；有效备份恢复 1 个月份，无效 JSON 显示错误且原记录仍保留。
- 布局与可访问性：1440 × 1000 和 390 × 844 均无页面级横向溢出；全零确认、删除、恢复、取消和文件选择均使用原生可聚焦控件，状态与错误通过 live region/alert 暴露；浏览器控制台无相关警告或错误。
- 自动验证：备份路由、格式校验、恢复事务、单月删除、全零确认和仓储回滚均有测试覆盖；完整命令结果见本次 Task 17 交付记录。
