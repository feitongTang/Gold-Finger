## Task 8: 基金赎回与本月净投入

验收日期：2026-08-21

- 环境：Next.js 16.3.1 生产构建、本地临时 SQLite 数据库、Codex 应用内浏览器。
- 录入：新增基金后，本月净投入允许填写 `-10000`；当前市值等其他金额仍保留非负限制。
- 保存与回显：保存成功后重载页面，基金本月净投入仍显示 `-10000`。
- 复盘：收入 25,000 元、支出 8,000 元、赎回 10,000 元时，投资净投入显示 -10,000 元，月度结余显示 27,000 元。
- 运行状态：页面无框架错误覆盖层，浏览器控制台无警告或错误。
