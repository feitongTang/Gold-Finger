# MVP Backlog

## Task 1: 月度快照持久化与固定投资分类

**Status:** Done

**Goal:** 建立后续所有用户流程依赖的月度现金流、现金资产、基金资产和负债数据模型。

**Done when:** SQLite schema 与迁移可从空数据库执行；每个自然月只能有一份快照；金额按非负值校验；`docs/product-scope.md` 中的固定投资分类可直接使用；仓储测试覆盖创建、更新、按月份读取和跨月份保留数据。

## Task 2: 首次使用与月度更新录入

**Status:** Done

**Goal:** 让个人用户通过一个连续流程完成首次资产录入，并在以后每月底更新现金流和资产快照。

**Done when:** 用户可在同一流程填写收入、支出、三类现金、基金名称/分类/市值/本月投入和花呗余额；投资投入由基金本月投入自动汇总；已有月份可继续编辑；输入错误有明确反馈；一次正常更新可在 5～10 分钟内完成。

## Task 3: 月度复盘结果

**Status:** Done

**Goal:** 在提交月度更新后立即展示该月资金分配、当前净资产和资产结构。

**Done when:** 用户可查看选定月份的收入、支出、投资投入和月度结余；可查看现金、投资、负债与净资产；投资组合按固定分类汇总；计算逻辑有独立单元测试并与已保存快照一致。

## Task 4: 历史月份与变化趋势

**Status:** Done

**Goal:** 让用户浏览任意历史月份并比较净资产、现金流和投资资产变化。

**Done when:** 用户可选择任意已有月份；可看到该月完整复盘结果；可按月份顺序查看净资产、现金流、现金资产、投资资产和负债的变化；缺失月份不会产生误导性的补值。

## Task 5: MVP 可用性与数据安全收尾

**Status:** Reopened

**Goal:** 将完整月度复盘闭环打磨到适合个人长期使用的最低可靠标准。

**Done when:** 首次录入、月度更新、结果查看和历史比较可在桌面端完成；空状态、加载和数据库错误可理解且可恢复；本地数据路径与备份方式有文档；核心流程通过端到端人工验收，`docs/product-scope.md` 的 MVP acceptance criteria 均有对应验证记录。

**Revalidation note:** 2026-08-26 深度体验复验发现新月份会沿用上月基金净投入，存在静默重复记账风险；错误定位、保存后查看结果和本地数据恢复也未达到长期使用的最低可靠标准。完成 Task 14、15、17 后重新验收。

## Task 6: 月度基金录入复用与投入一致性

**Status:** Superseded

**Goal:** 减少重复录入基金，并消除基金投入与现金流投资投入不一致的可能。

**Done when:** 新月份默认带出最近一个更早月份的基金名称、分类和市值，本月投入重置为零；基金字段明确标为本月投入；现金流投资投入由各基金本月投入自动汇总且不可单独编辑。

**Superseded by:** Task 8 保留正负净投入与自动汇总；Task 14 统一新的月份默认值规则。2026-08-26 实际体验确认当前实现会复用最近月份的基金净投入，与本任务的完成条件冲突。

## Task 7: 基金添加位置与投资组合比例下钻

**Status:** Done

**Goal:** 让基金录入入口紧跟基金列表，并用逐级比例视图呈现投资组合结构。

**Done when:** 添加基金入口位于最后一只基金下方；投资组合首层按资产大类展示当前市值比例，可继续下钻到市场和固定分类，但不展示具体基金；桌面端可操作。

## Task 8: 基金赎回与本月净投入

**Status:** Done

**Goal:** 支持通过负数记录基金赎回，同时保持月度现金流与基金投入汇总一致。

**Done when:** 基金本月净投入支持申购填正数、赎回填负数；正负金额自动汇总为投资净投入；负数能够保存、编辑和复盘；旧数据库升级后保留已有月度与基金数据；其他资产和负债金额仍按非负值校验。

## Task 9: 月度基金默认值与收益亏损估算

**Status:** Superseded

**Goal:** 减少月度基金重复录入，并让基金市值变化扣除资金进出后可直接理解。

**Done when:** 新月份沿用最近更早月份的基金净投入且当前市值留空；净投入字段按所选月份显示；已有前序记录时展示扣除当月净投入后的投资收益或亏损估算，首次记录不误算收益。

**Superseded by:** Task 10 已改为手动记录投资损益；Task 14 将撤销“沿用上月净投入”的旧要求。基金名称和分类继续复用，当前市值继续留空，本月净投入必须重置为零。

## Task 10: 月份导航与按需录入

**Status:** Done

**Goal:** 简化月度复盘首屏，并改用支付宝中的明确亏损数据进行手动记录。

**Done when:** 月份切换器位于本月结果与资金分配之间并支持左右逐月切换；月度表单默认收起，空月份显示“新建数据”，已有月份显示“更新数据”；复盘面板不再展示投资净投入；投资损益可按“收益为正、亏损为负”手动录入、保存和更新，旧月份默认为零；桌面端可操作。

## Task 11: 整体 UI 质感与空月份连续性

**Status:** Done

**Goal:** 在保持月度复盘简洁易用的前提下统一界面层级，并避免切换到空月份时出现明显的视觉断层。

**Done when:** 有数据与空月份共用稳定的复盘标题和月份导航，且仅保留下方月度记录入口；金额增减分别使用带正负号的绿色与红色表达，历史变化使用不带冗余前缀的语义标签；资金分配与资产结构按内容高度纵向排列，资产构成条有明确图例且负债比例仅在摘要框展示；整体视觉采用克制的磨砂玻璃质感以及统一的间距、颜色、圆角与交互状态；桌面端可操作并满足基本键盘与可访问性要求。

## Task 12: 预设主题色与全局主题切换

**Status:** Done

**Goal:** 提供低饱和度马卡龙与商务克制两类预设主题，让用户按偏好调整整个月度复盘界面。

**Done when:** 页头外观设置以按色相排列的常驻双色圆点提供红、粉、黄、绿、紫五套马卡龙与蓝、灰两套商务主题，两组之间使用轻量分隔；选择结果保存在本机并在刷新后恢复；页面背景、玻璃表面、导航、表单、按钮、标题、月度记录编号、焦点状态与数据强调色均使用主题语义色；桌面端可操作，并满足基本键盘、对比度与窄屏溢出检查。

## Task 13: 月度趋势图表

**Status:** Done

**Goal:** 用图表替代默认展开的月度变化表格，让资产与现金流趋势更容易识别。

**Done when:** 历史趋势默认展示净资产、现金和投资的资产变化折线图，负债可切换至独立量级查看，并展示可切换收入与支出的现金流折线图及最近六个已保存月份的平均值；缺失月份不补值；鼠标悬浮或键盘聚焦数据点时可查看精确金额；图例、坐标与交互可理解；原始趋势数据可按需展开查看；未明确的投资专项图表不提前实现。

## Task 14: 新月份基金安全默认值

**Priority:** P0

**Status:** Done

**Goal:** 消除新月份静默重复记录上月基金净投入的数据风险。

**Done when:** 新月份只继承最近一个更早月份的基金名称和固定分类；当前市值保持空白；每只基金的本月净投入统一重置为零；现金流投资净投入仍由基金明细自动汇总；单元测试覆盖正数申购和负数赎回均不会被带入新月份；桌面端人工验收确认预填值正确。

## Task 15: 月度录入入口、错误定位与保存闭环

**Priority:** P1

**Status:** Done

**Goal:** 让用户从开始录入到修正错误、保存并查看结果形成连续闭环。

**Done when:** 空月份的“新建数据”和已有月份的“更新数据”可在本月结果区域直接触发；展开表单后首个需要处理的字段进入可见区域；提交失败后聚焦并滚动到第一个错误字段，错误摘要可指出基金序号和字段；保存成功后自动收起表单并定位到更新后的本月结果，仍提供继续修改入口；键盘焦点顺序和 live region 反馈可理解。

## Task 16: 跨月数据一致性与趋势语义

**Priority:** P1

**Status:** Done

**Goal:** 帮助用户发现无法由现金流、投资净投入和投资损益解释的资产变化，并避免趋势颜色传达错误含义。

**Done when:** 有前序记录时展示净资产变化与已记录现金流、投资损益之间的可解释差额；投资组合总市值变化与上月总市值、本月净投入和手动投资损益存在差异时给出非阻塞提示；收入、净资产、现金、投资和结余按增长方向表达，支出与负债按相反业务语义表达；数字正负号始终保留数学方向；计算逻辑有独立单元测试。

## Task 17: 月度记录生命周期与本地数据恢复

**Priority:** P1

**Status:** Done

**Goal:** 避免误建无意义记录，并让长期本地财务数据具备可理解、可恢复的安全路径。

**Done when:** 全部金额为零且没有基金时，保存前明确确认将创建全零记录；用户可删除单个月份并看到不可逆提示；界面明确数据仅保存在本机；提供至少一种经过验证的导出、备份和恢复路径，并显示最近一次成功备份或导出状态；不会把真实数据库或备份写入 Git 跟踪范围。

## Task 18: 长期月份导航与图表精度

**Priority:** P2

**Status:** Todo

**Goal:** 让积累一年以上记录的用户仍能快速定位月份，并提升百分比和图表刻度的可信度。

**Done when:** 左右逐月切换保留，同时支持直接选择年月和查看全部已记录月份；缺失月份有明确状态但不会自动补值；投资分类显示的舍入百分比合计稳定为 100%；图表刻度根据数据范围选择显示精度，不出现相邻刻度文本相同；投资分类下钻同时显示比例和当前市值。

## Task 19: 轻量月度复盘上下文

**Priority:** P2

**Status:** Todo

**Goal:** 让用户在回看历史趋势时知道当月变化的背景，而不扩展为自动财务建议。

**Done when:** 每个月可保存简短的“本月发生了什么”和“下月关注什么”；备注随月份保存、更新和回显；新月份可选择继承上月现金和负债作为待确认值，继承值有明显标识；基金当前市值仍需确认，基金本月净投入始终为零。

**Goal:** 降低主题设置对核心任务的视觉干扰，并让历史月份文案更准确。
