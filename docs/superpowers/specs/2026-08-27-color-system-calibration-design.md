# Gold-Finger 整页颜色系统校准设计

日期：2026-08-27

## 背景与目标

当前页面已经以普鲁士蓝为主要强调色，但基础灰阶仍偏冷绿，且相同财务语义在不同组件中使用了不一致的蓝色。例如，“总资产构成”的投资段使用 `#536B89`，下方“投资组合分类”的比例条使用 `#003153`。页面同时存在多组接近但缺少明确职责的蓝灰色，降低了整体一致性。

本次校准以普鲁士蓝 `#003153` 与雾灰 `#E5DDD7` 为核心，建立可执行的颜色角色和跨组件映射。目标是保持桌面财务工具克制、清晰、可信的气质，同时避免大面积暖灰造成正文区域浑浊。

## 范围

本次只调整全局颜色令牌及现有组件的颜色映射，覆盖：

- 页面画布、页头、卡片、表单、浮层与辅助表面。
- 正文、说明文字、边框、焦点与交互状态。
- 净资产、现金、投资、收入、支出、负债与投资损益的展示颜色。
- 比例条、图例、趋势图、表格、提示状态与数据安全区域。

不调整布局、间距、字体、圆角、阴影结构、文案、数据计算、数据库、路由或交互流程。不增加移动端适配。

## 设计原则

1. **角色优先**：组件引用语义颜色角色，不自行选择相近色。
2. **同义一致**：同一财务含义跨组件复用同一色值或同一明确命名的色阶。
3. **重点克制**：`#003153` 只用于最高优先级操作、选中态、净资产和焦点，不用于普通标题装饰。
4. **雾灰限量**：`#E5DDD7` 用于轨道、边框和结构分隔，不大面积承载正文。
5. **颜色非唯一信号**：图表继续结合实线、虚线和点线；状态继续结合文字、符号和可访问标签。
6. **可读性优先**：正文与次级文字满足正常文本对比度；图形线条满足非文本对比度目标。

## 颜色角色

### 基础表面与文字

| 角色     | 色值      | 用途                                           |
| -------- | --------- | ---------------------------------------------- |
| 页面画布 | `#F6F8F8` | 全页背景与页头背景，保持接近白色的轻微冷雾蓝感 |
| 主表面   | `#FFFFFF` | 摘要卡片、表单、浮层和集中阅读区域             |
| 辅助表面 | `#F7F5F3` | 一致性提示、切换器轨道和弱分区                 |
| 标准雾灰 | `#E5DDD7` | 比例条轨道、边框和结构分隔                     |
| 主文字   | `#1D2C34` | 标题、正文、关键金额                           |
| 次级文字 | `#58676F` | 标签、说明、坐标与辅助信息                     |
| 反色文字 | `#FFFFFF` | 普鲁士蓝主按钮上的文字                         |

主文字在页面画布上的对比度约为 13.5:1，次级文字约为 5.5:1。

### 品牌与交互

| 角色     | 色值                 | 用途                                             |
| -------- | -------------------- | ------------------------------------------------ |
| 普鲁士蓝 | `#003153`            | 主按钮、关键选中态、净资产主序列、最高优先级强调 |
| 悬浮蓝   | `#002944`            | 主操作悬浮状态                                   |
| 按下蓝   | `#001F33`            | 主操作按下状态                                   |
| 柔和蓝面 | `#EAF0F2`            | 蓝色提示、文件选择和低强度选中背景               |
| 焦点环   | `rgb(0 49 83 / 32%)` | 键盘焦点轮廓                                     |

普通标题使用主文字色。普鲁士蓝不承担普通装饰色，以免页面出现过多同级强调。

### 财务数据

| 角色             | 色值      | 用途                                               |
| ---------------- | --------- | -------------------------------------------------- |
| 净资产           | `#003153` | 净资产趋势实线及最高优先级数据图形                 |
| 投资             | `#536B89` | 总资产投资段、投资图例、投资趋势、投资组合比例条   |
| 现金填充         | `#BBC6C8` | 总资产现金段与现金图例                             |
| 现金图表         | `#7C9398` | 现金趋势线；与现金填充同色相但加深以保持图形可读性 |
| 正向／收入       | `#3F6B5A` | 收入、收益、正向变化与成功状态                     |
| 负向／支出／负债 | `#98534E` | 支出、负债、亏损、负向变化与危险操作               |

现金使用明确的两级色阶，而非强行使用单一色值。填充色优先轻盈，图表色在页面画布上维持约 3:1 的图形对比度。投资在所有条状图中统一使用 `#536B89`，直接解决当前上下比例条深色不一致的问题。

### 状态反馈

| 角色       | 前景色    | 柔和背景  | 用途                             |
| ---------- | --------- | --------- | -------------------------------- |
| 成功       | `#3F6B5A` | `#EEF3F0` | 保存成功、正向结果               |
| 警告       | `#80663D` | `#F5F0E8` | 跨月复核与非阻断提醒             |
| 错误／危险 | `#98534E` | `#F6ECEA` | 校验错误、亏损、删除与不可逆操作 |

状态色只在有明确语义时出现，不用于一般装饰。颜色继续配合文字、正负号、图标或边框表达状态。

## 组件映射

### 应用外壳与导航

- 页面和页头使用页面画布色。
- 页头与内容区域通过标准雾灰边界区分。
- 月份切换按钮使用白色表面、雾灰边框和主文字；悬浮、焦点使用普鲁士蓝状态。

### 月度复盘摘要

- 净资产摘要使用白色主表面。
- 关键金额使用主文字色，主操作按钮使用普鲁士蓝。
- 跨月一致性提示使用辅助表面；仅警告值和警告标识使用警告色。
- 资金分配与资产结构使用白色表面和雾灰边框；负债与亏损使用负向色。

### 资产构成与投资组合

- 总资产构成：现金填充 `#BBC6C8`，投资填充 `#536B89`。
- 总资产图例与对应条段严格一致。
- 投资组合分类的所有完成比例使用投资色 `#536B89`。
- 上述所有比例条轨道统一使用标准雾灰 `#E5DDD7`。

### 趋势图与历史表格

- 净资产使用普鲁士蓝实线。
- 现金使用 `#7C9398` 虚线。
- 投资使用 `#536B89` 点线。
- 收入使用正向色，支出与负债使用负向色。
- 图表网格与坐标使用雾灰和次级文字色，不与数据序列竞争。
- 历史表格的正负变化继续保留正负号，并分别使用正向色与负向色。

### 表单、数据安全与浮层

- 输入框、表单卡片和浮层使用白色主表面与雾灰边框。
- 输入框聚焦使用普鲁士蓝边框和焦点环。
- 主按钮、次按钮、危险按钮分别使用品牌、结构和危险角色。
- 文件选择、恢复提示和弱选中状态使用柔和蓝面或辅助表面，不新增局部色值。
- 浮层可以保留轻微蓝灰阴影；普通卡片主要依靠表面与边框分层。

## 实施边界

- 优先修改 `src/app/globals.css` 中的颜色令牌与既有选择器映射。
- 不为颜色校准改写 React 组件；只有现有类名无法表达已确认语义时，才允许做最小类名调整。
- 更新 `src/app/design-system.test.ts`，验证核心色值与关键组件映射。
- 不新增运行时依赖或设计系统库。

## 验证策略

### 自动化验证

- 设计系统测试断言已确认的核心色值与语义映射。
- 运行格式检查、Lint、类型检查和全部 Vitest 测试。
- 因源代码发生变化，运行生产构建。

### 浏览器验证

在桌面视口检查：

1. 有数据月份的摘要、资产结构、总资产构成和投资组合分类。
2. 资产、负债、收入、支出趋势切换后的所有图表序列。
3. 展开的历史精确数据表。
4. 打开的新建／更新月度记录表单，包括焦点、错误和按钮状态。
5. 空月份与数据安全区域。

每个状态需要确认：页面身份正确、内容非空、无框架错误覆盖层、控制台无相关错误、颜色计算值符合映射、焦点清晰、文字与图形可读。当前 MVP 只验收桌面端，不增加移动端专项要求。

## 完成标准

- 页面整体呈现冷白、普鲁士蓝与克制雾灰的统一气质。
- `#E5DDD7` 可见但不大面积污染正文背景。
- 上下所有投资条状图的深色统一为 `#536B89`。
- 现金填充更轻、更干净，现金趋势仍具备足够辨识度。
- 同一财务语义跨图表、图例、比例条和数字状态保持一致。
- 不出现新增的无语义硬编码颜色，不改变任何业务行为。
